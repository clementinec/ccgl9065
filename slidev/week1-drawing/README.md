# CCGL9065 Week 1 — Drawing Set preview

This is a reversible, parallel visual treatment of the production Week 1
Slidev deck. The teaching content, sequence, speaker notes, embedded media,
contents menu and timer are copied from `../week1/`.

The original deck remains at `../week1/` and builds to `../../slides/week1/`.
This variant builds to `../../slides/week1-drawing/`.

Build from this directory with:

```sh
npm run build
```
